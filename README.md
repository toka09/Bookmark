# Bookmarker Website

This repository contains the code for a **Bookmarker** website that allows users to save website names and URLs for easy bookmarking. The website is built using **HTML5**, **CSS3**, **Bootstrap 5**, and **JavaScript**, with features such as input validation, event listeners, and DOM manipulation for a seamless and user-friendly experience.

---

## 📌 Overview

The Bookmarker website enables users to:

- Add and manage website bookmarks.
- Validate inputs for proper formatting.
- Interact dynamically with the UI using JavaScript.
- Update content without page reloads using DOM manipulation.

---

## ✅ Features

### 1. Validation

- Ensures users provide non-empty, correctly formatted website names and URLs.
- Prevents invalid data submissions.
- Improves the reliability and usability of the bookmarking process.

### 2. Event Listeners

- Reacts to user interactions like form submissions and button clicks.
- Connects UI actions with JavaScript functions for real-time behavior.

### 3. DOM Manipulation

- Updates the bookmarks list dynamically as users add or remove entries.
- No page reload is needed—enhancing user experience.

---

## 🛠️ Technologies Used

- **HTML5** – Defines the structure and layout of the site.
- **CSS3** – Adds styling and visual aesthetics.
- **Bootstrap 5** – Offers responsive design and pre-built UI components.
- **JavaScript** – Powers the app's interactivity, validation, and DOM updates.
